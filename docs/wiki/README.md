<div class="landing-band landing-privacy">
  <div>
    <p class="landing-eyebrow">YOUR DATA STAYS YOURS</p>
    <h2>Private by default.<br>Clear by design.</h2>
  </div>
  <div>
    <p>TimeLog follows a local-first approach. The desktop app stores records in a local SQLite database; the web app stores them in your browser. There is no mandatory account and the project does not use telemetry.</p>
    <p>You stay in control of your records, with built-in exports, backup and restore tools.</p>
  </div>
