# oXyFlow Documentation

Welcome to the technical documentation and user guide for **oXyFlow** — an ultra-lightweight, local-first work timer and task tracker available as a native desktop application (Tauri v2, Rust, SQLite) and as an instant **Web Application & PWA**.

> 🚀 **Live Web App**: Try oXyFlow directly in your browser or install it as an offline PWA at **[beoarcha.github.io/TimeLog/app/](https://beoarcha.github.io/TimeLog/app/)**.
