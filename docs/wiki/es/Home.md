**oXyFlow** es un temporizador de trabajo y gestor de tareas moderno y ligero, diseñado para profesionales independientes, programadores y quienes buscan concentrarse. Mide tu tiempo sin distracciones, sin nube y sin registros obligatorios.

```
   ┌─────────────────────────────────────────────────────────────┐
   │  ● Activo: [Rediseño Web] Boceto de Portada (01h 35m)       │
   │  [ Pausa ]   [ Cambiar tarea ]   [ Informes ]   [ Ajustes ] │
   └─────────────────────────────────────────────────────────────┘
```

---

## 🌟 ¿Por qué elegir oXyFlow?

- 🔒 **100% Privado y Local**: Todos tus datos se guardan exclusivamente en tu ordenador. Sin suscripciones en la nube ni rastreo.
- ⚡ **Rápido y Ligero**: Construido con Rust y Tauri v2. Consume menos de 40 MB de memoria RAM y abre al instante.
- 🎨 **12 Temas Atractivos**: Modo oscuro, claro, alto contraste y elegantes colores de acento (Esmeralda, Índigo, Ámbar, Rosa).
- 📊 **Informes Claros**: Vista diaria, resúmenes de horas y exportación en 1 clic a HTML, CSV o Excel para facturación.
- 💻 **Compañero de Terminal (`oxy`)**: Controla tus tareas desde PowerShell o terminal sin usar el ratón.
- 🌐 **6 Idiomas**: Disponible en español, inglés, polaco, alemán, francés y portugués de Brasil.

## 📥 Descarga e Instalación

Descarga la última versión desde la **[página de lanzamientos de GitHub](https://github.com/beoArcha/TimeLog/releases/latest)**:

| Sistema | Archivo recomendado | Descripción |
| :--- | :--- | :--- |
| **Windows** | `OxyFlow-Setup-x64.exe` | Instalador estándar de Windows con acceso directo |
| **Windows (Portable)** | `OxyFlow-Standalone-x64.exe` | Archivo ejecutable único sin instalación (para USB) |
| **macOS** | `OxyFlow-Universal.dmg` | Imagen de disco para Mac con Apple Silicon (M1–M4) e Intel |
| **Linux (AppImage)** | `OxyFlow-x86_64.AppImage` | Paquete portátil listo para ejecutar en cualquier Linux |
| **Linux (Debian/Ubuntu)** | `oxyflow_amd64.deb` | Paquete nativo para Ubuntu, Debian y Linux Mint |
| **Linux (Fedora/RHEL)** | `oxyflow.x86_64.rpm` | Paquete nativo para Fedora y Red Hat |
