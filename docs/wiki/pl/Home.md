**oXyFlow** to nowoczesny, niezwykle lekki licznik czasu pracy i zadań, stworzony dla freelancerów, programistów i wszystkich, którzy cenią skupienie. Mierz czas bez rozpraszaczy, bez logowania i bez wysyłania Twoich danych do chmury.

```text
   ┌─────────────────────────────────────────────────────────────┐
   │  ● Aktywne: [Nowa Strona WWW] Makieta Główna (01h 35m)       │
   │  [ Wstrzymaj ]   [ Zmień zadanie ]   [ Raporty ]   [ Opcje ] │
   └─────────────────────────────────────────────────────────────┘
```

---

## 🌟 Dlaczego oXyFlow?

- 🔒 **100% Prywatności**: Wszystkie Twoje dane zapisywane są wyłącznie na Twoim komputerze w lokalnej bazie. Brak kont, brak abonamentu i zero śledzenia.
- ⚡ **Błyskawiczne działanie**: Działa na silniku Rust i Tauri v2. Zużywa poniżej 40 MB pamięci RAM i uruchamia się w ułamku sekundy.
- 🎨 **12 Eleganckich Motywów**: Ciemny, jasny, wysoki kontrast oraz stylowe akcenty kolorystyczne (Szmaragdowy, Indygo, Bursztynowy, Różany).
- 📊 **Przejrzyste Raporty**: Wykresy dnia, zestawienia godzin i eksport jednym kliknięciem do HTML, CSV lub arkusza Excel dla klientów.
- 💻 **Pomocnik w Terminalu (`oxy`)**: Steruj stoperem prosto z wiersza poleceń lub PowerShell bez odrywania rąk od klawiatury.
- 🌐 **6 Języków**: Aplikacja dostępna po polsku, angielsku, niemiecku, hiszpańsku, francusku i portugalsku.

## 📥 Pobierz Program

Pobierz najnowszą wersję na swój system ze **[strony wydań na GitHubie](https://github.com/beoArcha/TimeLog/releases/latest)**:

| System | Zalecany plik | Opis |
| :--- | :--- | :--- |
| **Windows** | `OxyFlow-Setup-x64.exe` | Standardowy instalator z ikoną w menu Start |
| **Windows (Przenośny)** | `OxyFlow-Standalone-x64.exe` | Pojedynczy plik `.exe` bez instalacji (np. na pendrive) |
| **macOS** | `OxyFlow-Universal.dmg` | Obraz płyty dla komputerów z Apple Silicon (M1–M4) oraz Intel |
| **Linux (AppImage)** | `OxyFlow-x86_64.AppImage` | Uniwersalna, gotowa do uruchomienia paczka dla Linuxa |
| **Linux (Debian/Ubuntu)** | `oxyflow_amd64.deb` | Tradycyjna paczka `.deb` dla Ubuntu, Debiana i Mint |
| **Linux (Fedora/RHEL)** | `oxyflow.x86_64.rpm` | Paczka `.rpm` dla Fedory i Red Hata |
