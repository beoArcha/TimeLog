# ⏱️ Bienvenue sur oXyFlow

🌐 **Langue / Language**: [English](../Home.md) | [Polski](../pl/Home.md) | [Deutsch](../de/Home.md) | [Español](../es/Home.md) | **Français** | [Português (Brasil)](../pt-br/Home.md)

**oXyFlow** est un chronomètre de travail et gestionnaire de tâches ultra-léger et moderne, conçu pour les freelances, les développeurs et toute personne souhaitant se concentrer. Suivez vos heures sans distractions, sans cloud obligatoire et sans compte utilisateur.

```text
   ┌─────────────────────────────────────────────────────────────┐
   │  ● En cours : [Nouveau Site Web] Maquette Accueil (01h 35m) │
   │  [ Pause ]   [ Changer de tâche ]   [ Rapports ]   [ Options]│
   └─────────────────────────────────────────────────────────────┘
```

---

## 🌟 Pourquoi choisir oXyFlow ?

- 🔒 **100% Privé et Local** : Vos données restent exclusivement sur votre ordinateur. Aucun abonnement dans le cloud ni pistage.
- ⚡ **Ultra-rapide et Léger** : Développé en Rust et Tauri v2. Consomme moins de 40 Mo de RAM et s'ouvre instantanément.
- 🎨 **12 Thèmes Soignés** : Mode sombre, clair, contraste élevé et de superbes couleurs d'accentuation (Émeraude, Indigo, Ambre, Rose).
- 📊 **Rapports Précis** : Vue chronologique du jour, statistiques claires et export en 1 clic vers HTML, CSV ou Excel.
- 💻 **Compagnon Terminal (`oxy`)** : Contrôlez vos tâches directement depuis PowerShell ou le terminal.
- 🌐 **6 Langues** : Disponible en français, anglais, polonais, allemand, espagnol et portugais du Brésil.

## 📥 Téléchargement & Installation

Téléchargez la dernière version sur la **[page des versions GitHub](https://github.com/beoArcha/TimeLog/releases/latest)** :

| Système | Fichier recommandé | Description |
| :--- | :--- | :--- |
| **Windows** | `OxyFlow-Setup-x64.exe` | Installateur standard Windows avec raccourci menu Démarrer |
| **Windows (Portable)** | `OxyFlow-Standalone-x64.exe` | Fichier `.exe` unique sans installation (idéal pour clé USB) |
| **macOS** | `OxyFlow-Universal.dmg` | Image disque pour Mac Apple Silicon (M1–M4) et Intel |
| **Linux (AppImage)** | `OxyFlow-x86_64.AppImage` | Fichier exécutable portable pour toutes les distributions |
| **Linux (Debian/Ubuntu)** | `oxyflow_amd64.deb` | Paquet natif pour Ubuntu, Debian et Linux Mint |
| **Linux (Fedora/RHEL)** | `oxyflow.x86_64.rpm` | Paquet natif pour Fedora et Red Hat |
