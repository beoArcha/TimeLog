# ⏱️ Bem-vindo ao oXyFlow

🌐 **Idioma / Language**: [English](../Home.md) | [Polski](../pl/Home.md) | [Deutsch](../de/Home.md) | [Español](../es/Home.md) | [Français](../fr/Home.md) | **Português (Brasil)**

**oXyFlow** é um cronômetro de trabalho e gerenciador de tarefas moderno, superleve e direto ao ponto, criado para freelancers, desenvolvedores e profissionais focados. Acompanhe suas horas sem distrações, sem nuvem obrigatória e sem precisar criar contas.

```
   ┌─────────────────────────────────────────────────────────────┐
   │  ● Ativo: [Novo Site] Layout da Página Inicial (01h 35m)    │
   │  [ Pausar ]   [ Trocar tarefa ]   [ Relatórios ]   [ Opções]│
   └─────────────────────────────────────────────────────────────┘
```

---

## 🌟 Por que usar o oXyFlow?

- 🔒 **100% Privado e Local**: Todos os seus dados ficam salvos exclusivamente no seu computador. Sem assinaturas de nuvem nem rastreamento.
- ⚡ **Ultrarrápido e Leve**: Feito em Rust e Tauri v2. Usa menos de 40 MB de memória RAM e abre instantaneamente.
- 🎨 **12 Temas Elegantes**: Modo escuro, claro, alto contraste e belas cores de destaque (Esmeralda, Índigo, Âmbar, Rosa).
- 📊 **Relatórios Transparentes**: Linha do tempo do dia, resumo de horas e exportação em 1 clique para HTML, CSV ou Excel.
- 💻 **Companheiro de Terminal (`oxy`)**: Controle seus cronômetros direto pelo PowerShell ou terminal sem usar o mouse.
- 🌐 **6 Idiomas**: Disponível em português do Brasil, inglês, polonês, alemão, espanhol e francês.

## 📥 Baixar e Instalar

Baixe a versão mais recente na **[página de lançamentos do GitHub](https://github.com/beoArcha/TimeLog/releases/latest)**:

| Sistema | Arquivo recomendado | Descrição |
| :--- | :--- | :--- |
| **Windows** | `OxyFlow-Setup-x64.exe` | Instalador padrão para Windows com atalho no Menu Iniciar |
| **Windows (Portátil)** | `OxyFlow-Standalone-x64.exe` | Arquivo `.exe` único sem instalação (ótimo para pendrive) |
| **macOS** | `OxyFlow-Universal.dmg` | Imagem de disco universal para Mac com Apple Silicon (M1–M4) e Intel |
| **Linux (AppImage)** | `OxyFlow-x86_64.AppImage` | Pacote portátil pronto para rodar em qualquer Linux |
| **Linux (Debian/Ubuntu)** | `oxyflow_amd64.deb` | Pacote nativo para Ubuntu, Debian e Linux Mint |
| **Linux (Fedora/RHEL)** | `oxyflow.x86_64.rpm` | Pacote nativo para Fedora e Red Hat |
